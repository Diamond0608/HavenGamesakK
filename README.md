# HavenGamesakK
Our haven game


You are an Air Traffic Controller!
A game where you can lead planes to land at a runway or aircraft carrier. If you mess up and the planes collide - people die. The planes will blow up, the game will not end. The game is beyond that. Every couple of landings you can access a fighter jet that you control with WASD and you can left-click to destroy planes. Additional planes will not spawn in that time period. Drag planes and make sure the lines pass through the runways and not through any other aircraft's path. If you miss a plane it will hit the boundary and BOUNCE BACK at a greater speed. Be careful, miss too many and things will start to get hectic. A project for Hack Club Haven.
